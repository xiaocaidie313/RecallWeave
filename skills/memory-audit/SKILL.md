---
name: memory-audit
description: 核查一条回忆或过去对话的说法是否有原文依据。用户要求验证记忆、追溯来源、检查引用或纠正过去对话时使用。
---

先用 `search_memories` 找候选记忆。不要因为搜索结果出现就断言它相关；检查标题和摘要是否确实涉及用户的问题。

对相关候选，用其 `session_id`、`seq_start`、`seq_end` 调用 `get_messages` 核对原文。只有工具实际返回的消息可以作为原文依据；空结果或工具错误都不能算依据。

答复时区分“记忆摘要写了什么”和“原文实际说了什么”，列出可定位的会话 ID 与消息编号。若原文不支持说法，直接说明无法确认或需要纠正，不要补造证据。

如果出现多条看似相互印证的记录、需要判断是否为独立来源，再用 `read_skill_reference` 读取 `references/evidence-checklist.md`；普通核查不必读取。
